# Исправление запуска диктофона в этапе 2

Патч применяется поверх `Omni_Voice_Stage2_Whisper_Patch.zip`. В нём только
изменённые исходники, инструкции и тесты. EXE, модели и Python-окружения
не включены. Структуру папок нужно сохранить при распаковке.

## Что исправлено

Общий таймаут 60 секунд оставался и в этапе 2. Он охватывал запуск Python,
импорт Torch, загрузку Silero, библиотеки микрофона, проверку папки и очистку
аудио, но всегда сообщал, что не запустился Silero. Это сообщение не позволяло
определить настоящий этап зависания. По нему одному нельзя доказать, что
новое зависание вызвано той же DLL, что и прежний `WinError 1114` в `c10.dll`.

- Диктофон использует локальную ONNX-модель Silero 6.2.1 через CPU-движок
  sherpa-onnx. Исправление DLL Python ONNX Runtime описано отдельно в
  `VOICE_ONNX_DLL_FIX_RU.md`.
  Он не импортирует Torch, TorchAudio или Python-код пакета Silero. Веса
  берутся напрямую из установленного пакета; при записи нет скачиваний.
- Установка фиксирует sherpa-onnx/sherpa-onnx-core 1.13.8, NumPy 2.2.6,
  SciPy 1.15.3 и
  sounddevice 0.5.2 в отдельном `omni_voice_env`. Уже установленный Torch
  удалять не требуется. Окружение и параметры Whisper не изменяются.
- По умолчанию выбирается Python из `omni_voice_env`; скрытого перехода на
  Python Whisper при отсутствии голосового окружения больше нет. Ранее
  сохранённый пользовательский путь остаётся: проверьте его в настройках.
- До каждой блокирующей операции выводится этап запуска. Для этапов
  предусмотрены отдельные пределы ожидания, а весь запуск ограничен
  тремя минутами. Зависший процесс завершается; остановка во время запуска
  не превращается в ошибку таймаута.
- Ошибка содержит этап и фактический Python. По окончании попытки создаётся
  `voice-startup.log` в каталоге данных Omni; путь показывается в ошибке.
  Журнал сохраняет этапы и stderr, без аудио и расшифровок, и заменяется
  следующей попыткой. Самопроверка установки тоже ограничена по времени.
- Ошибка импорта необязательной очистки WAV показывает предупреждение,
  сохраняя возможность записать оригинал. Сегментация речи, паузы,
  сохранение WAV и автоматическая очередь Whisper продолжают использовать
  прежние настройки.

## Как применить на ноутбуке

1. Остановите диктофон и полностью закройте Omni через меню значка в трее.
2. Распакуйте ZIP в корень проекта, рядом с `BUILD_WINDOWS.cmd`, с заменой
   файлов.
3. В PowerShell из папки проекта обновите отдельное окружение:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\SETUP_VOICE_WINDOWS.ps1
   ```

   Используется ваш базовый Python:
   `C:\Users\User\Desktop\whisper_env\Scripts\python.exe`.
   Скрипт проверяет Python 3.10–3.13 x64, локальную модель, PortAudio и
   библиотеки очистки. Он не начинает запись и не загружает Whisper.
   При сообщении о недостающей Windows DLL доступен прежний параметр
   `-InstallVCRuntime` для установки подписанного Microsoft Visual C++ Runtime.

4. Обновите приложение обычной сборкой:

   ```powershell
   .\Build_windows
   ```

   Для запуска исходников можно использовать `START_WINDOWS.cmd`.
5. В **Настройки микрофона → Выбрать Python** укажите:
   `C:\Users\User\Desktop\omni_voice_env\Scripts\python.exe`.
   Это особенно важно, если раньше в настройках сохранился `whisper_env`.
   Обновите список микрофонов и начните запись. Для автоподхвата включите
   **Автоматически распознавать новые записи**.

Повторная диагностика без переустановки:

```powershell
& "$env:USERPROFILE\Desktop\omni_voice_env\Scripts\python.exe" -u .\scripts\check-voice-runtime.py --audio --timeout 90
```

Для нестандартного расположения используйте параметры `-BasePython` и
`-VoiceEnvironment` установочного скрипта и соответствующий Python в Omni.

## Проверка и ограничения

Проверены реальные дочерние Python-процессы с заменами ML-библиотек для
тестов: этапы запуска, таймаут этапа и общий предел, принудительное
завершение, отмена, журнал, отсутствие импорта Torch, локальные веса,
PCM и состояние Silero. Проверены оригинал WAV при сбое очистки и работа
очереди этапа 2: TXT/JSON, единственное распознавание, повтор, отмена,
сохранение истории и переиспользование модели.

Проверена доступность готовых пакетов Windows x64 для вашего Python 3.11.
В этой среде нет Windows, PowerShell, физического микрофона и вашей модели
Whisper. Новый CPU-движок sherpa-onnx с настоящими весами Silero прошёл
самопроверку в Linux. Успешную инициализацию DLL на
вашем ноутбуке подтвердит самопроверка после установки; она не заявлена
как уже выполненная проверка Windows.
