ЗАМЕНА ЛОГОТИПА OMNI

Положите свою картинку omni.png в корень проекта, рядом с BUILD_WINDOWS.cmd
и BUILD_ANDROID.cmd. Не в папку dist и не внутрь android.

Пример:
Omni_Reader_Native_0.3.0\omni.png
Omni_Reader_Native_0.3.0\BUILD_WINDOWS.cmd
Omni_Reader_Native_0.3.0\BUILD_ANDROID.cmd

Лучше использовать квадратную PNG-картинку 512 x 512 или 1024 x 1024
с прозрачностью. Неквадратное изображение сохраняет пропорции.
Допустимо до 4096 пикселей по стороне и 16 МиБ.

Запустите обычную сборку для своей платформы. Она автоматически заменит
логотип внутри приложения, значки Windows и Android. Для запуска Windows
без установщика работает START_WINDOWS.cmd. Для веб-версии: npm run build.
Готовую Android-сборку потребуется установить заново на телефон.

ПАНЕЛЬ ЗАДАЧ WINDOWS
Для значка установленного Omni сначала примените исправление настроек
Windows-сборки, затем запустите BUILD_WINDOWS.cmd и установите новую версию.
В desktop/package.json параметр build.win.signAndEditExecutable должен
быть true: он разрешает встраивание icon.ico в исполняемый файл.

Закройте Omni, открепите старый значок на панели задач, запустите установленный
Omni Reader через меню «Пуск» и закрепите его заново. Используйте установленное
приложение: START_WINDOWS.cmd запускает среду разработки Electron.

Если omni.png отсутствует, сохраняется текущий логотип.
Архив исправления не содержит вашей картинки или готовых EXE/APK.
