OMNI 0.3 ДЛЯ НОУТБУКА — РЕДАКТИРОВАНИЕ И РЕЖИМЫ ПРОСМОТРА

1. Распакуйте архив целиком в обычную папку.
2. Установите Node.js 22.12 или новее с npm.
3. Запустите START_WEB.cmd — приложение откроется в браузере.
   Оставьте окно локального сервера открытым.
   Для этого запуска готовые ресурсы уже включены; npm install не нужен.
4. Для отдельного окна приложения используйте START_WINDOWS.cmd.
   При первом запуске нужен интернет для установки Electron и зависимостей.
5. Для создания установщика используйте BUILD_WINDOWS.cmd.

Включены прямое редактирование DOCX/PPTX, B/I/U/S, спецсимволы,
новые страницы/слайды/разделы, undo/redo, расширенный режим,
прокрутка по умолчанию и переключение «Прокрутка / По страницам».
Остальные редакторы сохранены. Готовый EXE не включён.

Сначала нажмите «Редактировать», затем щёлкните текст прямо на странице.
«Сохранить копию» создаёт отдельный файл и предлагает экспорт.
Исходный файл не перезаписывается.

Исходники, ресурсы и lock-файлы включены. node_modules, кэш и дублируемые
ресурсы оболочек не включены; копии www создают скрипты автоматически.
Контрольный статус и ограничения — docs/VALIDATION_RU.md.
Полная инструкция — README_RU.md.

Проверки движков и экспортов прошли; запуск на Windows и визуальная
приёмка ещё требуют проверки на ноутбуке.
