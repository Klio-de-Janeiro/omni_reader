# Omni Reader 0.3 — проект для ноутбука

В архиве исходники и готовые локальные ресурсы приложения с восстановленным inline-редактором и режимами просмотра. Готовый установщик EXE не включён.

## Запуск на Windows без сборки установщика

1. Полностью распакуйте архив в обычную папку.
2. Установите Node.js **22.12 или новее** с npm.
3. Для запуска в браузере дважды нажмите **START_WEB.cmd**. Откроется http://127.0.0.1:4173. Оставьте окно локального сервера открытым; для остановки закройте его. npm-зависимости для этого запуска скачивать не нужно — ресурсы уже включены.
4. Для отдельного окна Windows запустите **START_WINDOWS.cmd**. При первом запуске нужен интернет для установки зависимостей и бинарника Electron. Повторные запуски используют установленный комплект, пока lock-файл не изменился.

Не открывайте dist/index.html двойным щелчком: модули и изолированный просмотр Office работают через локальный сервер либо оболочку Electron.

## Что работает

- PDF, DOCX и PPTX открываются с прокруткой: страницы/слайды идут подряд. **Режим → Прокрутка / По страницам** переключает показ без перезагрузки, сохраняя текущую страницу и масштаб.
- **Редактировать** в DOCX/PPTX: щёлкните текст прямо на странице или слайде. Дополнительное окно ввода не открывается.
- Жирный, курсив, подчёркивание, зачёркивание и панель **Ω** со спецсимволами. Выделите текст перед изменением оформления; без выделения выбранное оформление действует на следующий ввод.
- **+ Абзац / + Страница** для DOCX; **+ Слайд / + Раздел** для PPTX. Слайды и разделы сохраняются в структуре PowerPoint.
- Отмена/повтор до 100 действий; последовательный ввод группируется. **Сохранить копию** сохраняет текст и оформление в исходном формате, добавляет копию в список и предлагает экспорт.
- **На весь экран** расширяет рабочую область с доступными элементами управления; **Файлы** скрывает боковую панель.
- OGG: воспроизведение, перемотка и скорость. **Конвертировать → В WAV** создаёт PCM 16-bit WAV локально. Для Vorbis сохраняется частота 8–96 кГц, для Opus используется 48 кГц; 1–8 каналов. OGG редактируется после конвертации в WAV. Результат должен быть меньше 500 МБ; декодирование больших записей зависит от памяти устройства.
- Остальные редакторы сохранены: ячейки XLSX/CSV, поворот/удаление страниц PDF, обрезка/поворот JPG/PNG, обрезка/громкость WAV PCM 16-bit.
- Поиск, выделение, копирование, навигация, масштаб и локальное хранение копий. Содержимое файлов обрабатывается на устройстве.

Управление и ограничения: docs/EDITING_RU.md. Фактические проверки: docs/VALIDATION_RU.md.

## Горячие клавиши DOCX/PPTX

| Клавиши | Действие |
|---|---|
| Ctrl+B / Ctrl+I / Ctrl+U | Жирный / курсив / подчёркивание |
| Ctrl+Shift+X | Зачёркивание |
| Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z | Отмена / повтор |
| Ctrl+S | Сохранить копию |
| Ctrl+Enter | Новая страница DOCX или слайд PPTX |
| Ctrl+Alt+N | Новый слайд PPTX |
| Ctrl+Shift+Enter | Новый раздел PPTX |
| Ctrl+Shift+F / Esc | Расширенный режим / выход из него |

## Сборка установщика Windows

Запустите BUILD_WINDOWS.cmd. Нужны Windows 10/11 x64, Node.js 22.12+, npm и интернет при первой сборке. Результат:

    release/windows/Omni-Reader-0.3.0-Windows-Setup.exe

Исправление npm **EALLOWGIT** включено: Git-зависимость Electron node-gyp заменена точной опубликованной версией; зависимости зафиксированы в desktop/package-lock.json. Глобальные настройки npm менять не нужно. Предупреждения deprecated сами по себе не означают провал сборки.

## Исходники и проверки

    npm ci
    npm run build
    npm test
    npm run native:sync

dist/ содержит готовые ресурсы. scripts/ содержит входы сборки и OOXML-редакторы. Копии desktop/www и android/app/src/main/assets/www создаёт scripts/sync-native.mjs; скрипты запуска/сборки вызывают его автоматически. В архиве эти копии не дублируются.

Независимая проверка экспортов после тестов:

    py -m pip install python-docx python-pptx openpyxl pypdf
    py tests/independent_readers.py

Браузерные сценарии:

    npx playwright install chromium --only-shell
    npm run test:e2e

## Android

Исходный Android-проект сохранён. Для сборки используйте BUILD_ANDROID.cmd, Android Studio, JDK 17+, Android SDK Platform 35 и Build-Tools 35.0.0. При первом запуске скачивается Gradle с проверкой SHA-256. Результат — debug APK. В этой среде APK не собирался; интерфейс на телефоне не проверен.

## Границы возможностей

Omni — базовый редактор и предпросмотр Office. Сложная вёрстка может отличаться от Word/PowerPoint. Абзацы с полями, ссылками, рисунками или другими сложными встроенными объектами остаются доступны для чтения; абзацы, разделённые просмотрщиком на части между страницами, также не редактируются напрямую. Основной текст DOCX и текстовые блоки PPTX редактируются; колонтитулы и заметки не являются отдельными инструментами редактирования.

Шрифты, изображения, формы и положение объектов Office не редактируются. Длинный текст может выйти за границы исходного слайда. Конвертация между форматами, OCR, автосохранение черновиков, выполнение макросов и пересчёт формул не добавлялись. После аварийного закрытия несохранённый черновик теряется.

Размер каждого поддерживаемого файла: меньше 500 000 000 байт. Тексты больше 8 МиБ обрабатываются частями, CSV — блоками строк; сложность Office, разрешение изображений (40 Мп) и доступная память остаются ограничениями. Это не гарантия открытия любого файла на любом устройстве. Ячейка и редактируемый абзац: до 32767 символов. Интерфейс, установка и системный экспорт непосредственно на Windows ещё требуют проверки.

Обновление конвертера, автосохранения и DOC описано в `PATCH_CONVERTER_RU.md`.
