# Этап 4: локальный Qwen и напоминания

Патч для Windows накладывается на проект с этапом 3 и ранее отправленным
исправлением DLL Silero. Распакуйте ZIP в корень проекта с заменой файлов.
Собранных EXE, моделей и виртуальных окружений в архиве нет.

## Запуск

1. Запустите ваш локальный сервер Qwen. Omni использует уже установленную модель
   и не скачивает новую. По умолчанию выбран Ollama, `http://127.0.0.1:11434`.
2. Откройте **START_WINDOWS.cmd**, затем **Голосовые команды и напоминания**
   в боковой панели Omni → **Настройки локального Qwen**.
3. Укажите сервер и адрес. Для Ollama оставьте адрес выше. Для LM Studio или
   совместимого сервера выберите соответствующий пункт и задайте
   `http://127.0.0.1:1234/v1` либо ваш локальный порт.
4. Нажмите **Обновить модели**, выберите точное имя установленной Qwen в поле
   модели и нажмите **Сохранить**. Сервер должен поддерживать JSON-схемы.
   Адрес принимается только для localhost / 127.0.0.1 / ::1, без редиректов.
5. Проверьте часовой пояс, например `Europe/Moscow`. По умолчанию он берётся из
   системы. Включите **Обрабатывать новые обращения «Омни»** и сохраните.
6. В настройках микрофона включите автоматическое распознавание, затем явно
   нажмите **Начать запись**. Существующие пути Python и Whisper сохраняются.

Для установленного Ollama список можно сверить в PowerShell: `ollama list`.
Omni не запускает и не завершает сам сервер модели. Ключи авторизации локального
API в этом этапе не добавлены. Для LM Studio загрузите модель и включите Local
Server; в поле адреса используйте его фактический порт.

## Что работает

- Обращение «Омни» / Omni в начале новой распознанной фразы запускает обработку.
  Обычный разговор и записи эталонов/калибровки не создают предложения.
- Можно отправить команду текстом для проверки подключения без микрофона.
- Qwen определяет одно из разрешённых намерений: создать, перенести, завершить
  напоминание, обновить прогресс, предложить режим датасета, уточнить или пропустить.
  Программы, команды PowerShell, действия с чужими файлами и сообщения не исполняются.
- Карточка показывает исходную фразу, название, конкретные дату/время и часовой
  пояс. Поля можно исправить. **Подтвердить и сохранить** фиксирует действие;
  **Отклонить** отменяет предложение. До подтверждения задачи не меняются.
- Для «Омни, готово» или «Омни, выполнено 3 из 5» сначала выберите открытую задачу
  в списке. Выбор общий для окон текущего сеанса. Без ясной ссылки помощник просит
  уточнение; он не выбирает последнюю задачу автоматически. Одинаковые названия
  тоже требуют выбора. Выбор сбрасывается при перезапуске и завершении задачи.
- Список задач содержит состояние, дату, прогресс и историю подтверждённых
  изменений. Есть страницы для истории команд и списка задач.
- В режиме **Сбор датасета** новые голосовые команды не обрабатываются. Голосовое
  переключение требует подтверждения. Оно не включает микрофон, не подтверждает
  владельца и не экспортирует аудио автоматически. Отбор и экспорт остаются
  в разделе **Мой голос и датасет**.
- Переключатель **Только проверенный голос владельца** выполняет проверку этапа 3
  перед Qwen. Сначала нужны эталоны и калибровка. Неподтверждённый голос даёт
  видимую ошибку и не передаёт фразу модели. Текстовая команда вводится вами явно.

## Время

«Через час» и подобные интервалы считаются от `started_at` исходного WAV,
а не от окончания очереди Whisper/Qwen. Секунды сохраняются в карточке.
Поддерживаются числовые интервалы секунд/минут/часов/дней/недель, основные
русские числительные, полчаса, полтора часа, сегодня/завтра/послезавтра,
дни недели с точным временем, даты `ГГГГ-ММ-ДД` и `ДД.ММ.ГГГГ`.

Дни и недели считаются по календарю указанного пояса; часы и минуты — как
длительность. Фразы без дня/времени, приблизительные или конфликтующие даты,
несуществующее/повторяющееся время при переводе часов требуют уточнения.
Сложный интервал «час и 30 минут» уточняется как «90 минут».
Импортированный WAV без исходного времени не получает придуманную дату.
Если срок уже прошёл во время обработки, карточка просит новую дату.

Qwen возвращает исходную фразу о времени, а дату вычисляет код Omni из исходного
текста. Подмена моделью фразы о времени приводит к уточнению. В базе хранятся
UTC и исходный часовой пояс. После подтверждения изменить дату можно новой
командой переноса с выбором конкретной задачи и повторным подтверждением.

## Производительность и хранение

Для i3-1305U установлены 4 потока Qwen, температура 0 и таймаут 300 секунд.
Потоки Ollama можно менять от 1 до 6, таймаут от 30 до 1800 секунд.
Ollama получает настройку CPU; LM Studio настраивается при загрузке модели
на сервере. Whisper и Qwen используют общую очередь CPU. Перед Qwen закрывается
простаивающий worker Whisper, после ответа Ollama получает `keep_alive: 0`.
Диктофон продолжает сохранять WAV во время обработки.

Настройки и задачи: `voice-assistant/reminders.sqlite` внутри каталога данных
Omni. Полный путь показан в панели. SQLite встроен в поставляемый Electron;
отдельные npm-модули SQLite, Torch и Python ONNX Runtime для Qwen не нужны.
Диагностика последнего запроса: `voice-qwen.log` в каталоге данных Omni.
Она содержит адрес, модель, идентификатор и ошибку, без аудио и полного транскрипта.
Скрипт с путями и параметрами Whisper остаётся `desktop/speech-defaults.json`;
пользовательские настройки Whisper этот патч не сбрасывает.

Очередь Qwen ограничена 24 командами, текст команды — 8192 байтами; каталог
ограничен 5000 предложениями и 5000 задачами. При переполнении исходные WAV/TXT
сохраняются. Ошибку можно повторить; запрос можно отменить. Подтверждение одной
карточки повторно не создаёт дубликат. Конфликт изменений в разных окнах требует
повторного просмотра. Черновик карточки и настройки сохраняются при фоновых
обновлениях в открытом окне; несохранённые черновики не переживают закрытие окна.
После перезапуска задачи остаются, прерванные запросы требуют ручного повтора.
Выход из Omni и сон Windows отменяют текущую обработку; микрофон при запуске
и пробуждении сам не включается.

## Проверка и следующий этап

Автотесты проверяют реальные транзакции SQLite, схемы запросов к локальному
HTTP-серверу, даты/часовые пояса/DST, очередь Whisper→Qwen, активацию, отмену,
ограничения, выбор задачи, подтверждение, повторы, перезапуск и безопасный DOM.
Выполнено: `npm test` — 208 тестов, ошибок нет; `npm run build` — 378 ресурсов;
`npm run native:sync` — обновлены копии ресурсов. Также проверены синтаксис новых
модулей, наличие исходников из BUILD_WINDOWS.cmd и модуль в офлайн-кеше.
Полный набор предыдущих этапов включён в `npm test`. Установщик здесь не собирался;
на вашем Windows остаётся прежняя команда `.\BUILD_WINDOWS.cmd`.

В этой среде нет вашей модели Qwen, физического микрофона и Windows. Поэтому
скорость и качество понимания проверяются на ноутбуке: сначала команда текстом,
затем фраза «Омни, напомни завтра в 19:00 решить задачи», проверка карточки,
подтверждение и перезапуск Omni. Отдельно проверьте отмену, неверный адрес сервера
и включение проверки владельца после калибровки.

**Этап 5:** планировщик, системные Windows-уведомления, доставка пропущенных после
сна/перезапуска и защита от повторной доставки. На этапе 4 напоминания сохраняются,
но уведомления по времени ещё не отправляются.

[LM Studio structured output](https://lmstudio.ai/docs/developer/openai-compat/structured-output).
