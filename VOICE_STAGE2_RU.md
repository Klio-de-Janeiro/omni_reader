# Omni: этап 2 — диктофон и локальный Whisper

Это патч исходников для Windows поверх последнего обновления диктофона
`Omni_Recorder_Windows_Update.zip`. Готовых EXE, Python-окружений и моделей
в архиве нет.

Исправление прежнего таймаута запуска Silero и обновление отдельного
Python-окружения описаны в `VOICE_STARTUP_FIX_RU.md`. Диктофон использует
локальную ONNX-модель без Torch; очередь Whisper работает в своём окружении.

## Установка и запуск

1. Остановите запись и полностью закройте Omni через меню значка в трее.
2. Распакуйте архив в корень проекта, где находится `BUILD_WINDOWS.cmd`,
   согласившись на замену файлов. Сохраните структуру папок.
3. В PowerShell из папки проекта выполните:

   ```powershell
   .\Build_windows
   ```

   Установщик будет создан на вашем компьютере в
   `release\windows\Omni-Reader-0.3.0-Windows-Setup.exe`.
   Чтобы запустить исходники для разработки, можно использовать имеющийся
   `START_WINDOWS.cmd`.
4. Откройте **Настройки микрофона**, включите **Автоматически распознавать
   новые записи** и нажмите **Начать запись**. После выбранной паузы WAV
   сохраняется и попадает в очередь. Переключатель применяется сразу,
   включая текущую запись. По умолчанию он выключен и сохраняется между
   запусками Omni.

Дополнительные пакеты для Whisper этот патч не устанавливает: используется
ваше рабочее окружение. Если после предыдущего патча ещё не обновляли
окружение Silero/очистки WAV, сначала выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\SETUP_VOICE_WINDOWS.ps1
```

## Пути и параметры

Whisper и микрофон используют разные окружения:

- Whisper: `C:\Users\User\Desktop\whisper_env\Scripts\python.exe`.
- Модель: `C:\Users\User\.cache\huggingface\hub\models--Systran--faster-whisper-small\snapshots\536b0662742c02347bc0e980a01041f333bce120`.
- Silero: `C:\Users\User\Desktop\omni_voice_env\Scripts\python.exe`.

В панели есть **Настройки Whisper**: пути, язык, температура, beam size и
остальные уже существовавшие параметры. Настройки общие с ручным
распознаванием открытых WAV/OGG; ранее сохранённые пути сохраняются.
Для изменения параметров при заполненной очереди нажмите **Приостановить
очередь**, дождитесь текущего фрагмента или отмените его, сохраните
параметры, затем нажмите **Продолжить очередь**.

Обработка выполняется на CPU. Автоматический режим при значении
`cpu_threads = 0` использует 4 потока; явно заданное число сохраняется.
Silero использует 1 поток. GPU не требуется. Для faster-whisper сохранены
`vad_filter=False`, `local_files_only=True` и режим без загрузок из сети.
Модель остаётся загруженной между последовательными фрагментами и
освобождается после 30 секунд простоя. Новые параметры декодирования
применяются к следующему фрагменту.

## Очередь и файлы

- Завершённые оригиналы WAV обрабатываются последовательно. Очистка WAV
  и запись микрофона продолжают работать независимо от распознавания.
- Одновременно выполняется только одна задача Whisper во всём Omni,
  включая ручное распознавание открытого файла. Автоочередь ждёт окончания
  ручной задачи.
- В истории отображаются **В очереди**, **Распознаётся**, **Готово**,
  **Ошибка**, **Речь не обнаружена** и отменённые фрагменты. Для записей
  без автоподхвата доступна кнопка **Распознать**.
- **Показать текст** выводит расшифровку прямо в панели. Обычный результат
  сохраняется в `<имя WAV>.txt` рядом с записью. Повтор сохраняет новый
  файл `-transcript-2.txt` и далее, сохраняя прежние расшифровки.
- `<имя WAV>.transcription.json` хранит статус, фактически использованные
  настройки, номер попытки, время и путь к TXT. JSON исходного фрагмента
  содержит ссылку `transcription_file` на этот файл. Раздельные JSON
  предотвращают конфликт с одновременным созданием очищенной копии.
- Для новых фрагментов хранится история до 100 записей; панель показывает
  30 последних. Исходные аудио и расшифровки при сокращении истории не
  удаляются. История сохраняется между запусками приложения.
- Очередь ограничена 24 фрагментами и суммарно 60 минутами ожидающего и
  обрабатываемого аудио. Переполнение оставляет WAV и показывает ошибку
  с возможностью повтора. Новые записи микрофона сохраняются.
- Ошибка Whisper приостанавливает очередь. Исправьте настройки и нажмите
  **Повторить** или **Продолжить очередь**. Пустой результат не создаёт TXT
  и не блокирует следующие фрагменты. Ошибка сохранения TXT показывается;
  в панели остаётся предпросмотр первых 2000 символов результата.
- Выключение автоподхвата действует на новые фрагменты. Уже поставленные
  задачи продолжаются. Для отдельной задачи есть **Отменить распознавание**;
  для всей очереди — приостановка.
- Остановка микрофона сохраняет последнюю фразу; очередь продолжает
  работу. Закрытие окна при активной записи или распознавании сворачивает
  Omni в трей. **Выйти из Omni** останавливает запись и отменяет активное
  распознавание. После запуска прерванные задачи можно повторить вручную;
  автоматический запуск микрофона и очереди при старте не добавлен.

Распознаётся любая речь, которую выделил Silero: проверка личности
говорящего относится к дальнейшим этапам. Команды Qwen и напоминания в
этот патч не входят. Телефонный интерфейс не получает эти элементы.

## Проверка

Проверены протокол с реальным Python-процессом и заменами моделей для
тестов, сохранение UTF-8 TXT/JSON, повтор без перезаписи, единственная
задача Whisper, переиспользование модели, отмена, ошибки, переполнение,
история, переключение автоподхвата и DOM интерфейса. Общие тесты проекта
прошли, после последних изменений повторены затронутые проверки.
`npm run build` обновляет ресурсы без сборки EXE.

В этой среде нет вашего Whisper Small, Windows и физического микрофона.
Реальное качество распознавания, производительность ноутбука и Windows
сборка здесь не проверены. Ручная приёмка: две фразы с паузой → два WAV и
два TXT; остановка микрофона → завершение очереди; повтор → новый TXT;
выход → отсутствие работающих процессов записи/Whisper.
