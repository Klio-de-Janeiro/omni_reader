# Локальное распознавание речи в Omni для компьютера

## Установка патча

Закройте Omni. Распакуйте архив в корень исходного проекта, где находится
`BUILD_WINDOWS.cmd`, с заменой файлов и сохранением папок `desktop`, `dist`, `tests`.
Патч настроек предназначен для текущей версии проекта, где уже применён
`Omni_Whisper_Desktop_Patch.zip`; это архив заменяемых и новых файлов,
а не полный проект.
Запустите `START_WINDOWS.cmd`. Чтобы обновить установленную программу, соберите
новый установщик через `BUILD_WINDOWS.cmd` и установите его. Скомпилированных
EXE, Python, моделей Whisper и FFmpeg в этом архиве нет.

## Первый запуск

В новой версии уже подставлены ваши пути:

- Python: `C:\Users\User\Desktop\whisper_env\Scripts\python.exe`.
- Small: `C:\Users\User\.cache\huggingface\hub\models--Systran--faster-whisper-small\snapshots\536b0662742c02347bc0e980a01041f333bce120`.

Откройте OGG/WAV и нажмите **Распознать речь**. Если ранее вы сохранили другие
пути, они сохраняют приоритет. Кнопка **Восстановить значения по умолчанию**
вернёт указанные выше пути и исходные параметры. Пустые или отсутствующие пути
также получают эти значения по умолчанию.

Чтобы выбрать другое окружение или модель:

1. Откройте запись `.ogg` или `.wav` с диска в Omni.
2. Под аудиоплеером нажмите **Настройки Whisper**.
3. Выберите **Python** именно из окружения, где установлен ваш Whisper.
   Для Windows это обычно `папка_окружения\Scripts\python.exe`.
   Узнать точный путь можно в терминале с активированным окружением:
   `python -c "import sys; print(sys.executable)"`.
4. Выберите уже скачанную модель:
   - OpenAI Whisper: файл `small.pt` через **Выбрать .pt**.
     Часто он находится в `%USERPROFILE%\.cache\whisper\small.pt`.
   - faster-whisper: **Выбрать папку**, в которой лежат `model.bin`,
     `config.json` и `tokenizer.json`. При скачивании через Hugging Face выбирайте
     папку конкретного снимка модели, а не корень кеша.
5. Для `.pt` нужен FFmpeg: если он уже доступен через PATH, выбирать его не надо.
   Иначе укажите установленный `ffmpeg.exe`. Для папки faster-whisper этот шаг не нужен.

Настройки сохраняются для следующих запусков приложения. Для русского языка
используйте многоязычную Small, а не `small.en`. Формат whisper.cpp `.bin`
этот патч не поддерживает.

Python должен содержать библиотеку, соответствующую выбранной модели.
Если скачана только модель, для `.pt` потребуется `openai-whisper`, для папки
с `model.bin` — `faster-whisper`. Приложение показывает отсутствующий модуль
и позволяет выбрать другое, уже настроенное окружение; ничего не устанавливает
и модели автоматически не скачивает.

## Использование

Нажмите **Распознать речь** под аудиоплеером. Распознавание выполняется локально
на CPU, по умолчанию язык — русский. После завершения текст появится на странице, а рядом
с записью создастся файл UTF-8: `запись.ogg` → `запись.txt`.
В faster-whisper текст дополнительно появляется по мере получения фрагментов.
Для OpenAI Whisper полный текст появляется после завершения обработки.

Если `запись.txt` уже существует, создаётся `запись-transcript-2.txt`, затем
`запись-transcript-3.txt` и так далее. Исходная запись и существующий текст
не перезаписываются. Если папка не разрешает запись, результат остаётся на
странице: его можно скопировать. Сохранение расшифровки не зависит от переключателя
сохранения документов внутри Omni.

У сохранённой внутри приложения копии может отсутствовать путь к оригиналу.
В этом случае Omni предложит выбрать исходную OGG/WAV на диске, чтобы знать,
какую запись распознавать и куда сохранить текст. Для обычного открытия файла
с диска дополнительный выбор записи не нужен. После перезапуска приложения
откройте запись с диска заново, если старый источник больше недоступен.

Кнопка **Отменить распознавание**, закрытие записи или её окна останавливают
задачу. Одновременно выполняется одна задача Whisper. Скорость зависит от CPU
и продолжительности записи. Поддерживаются файлы меньше 500 МБ; длительная
запись может потребовать много времени и памяти.

Функция доступна только в настольном Electron-приложении. Android и веб-версия
не показывают кнопку и не запускают Python. В faster-whisper VAD отключён,
поэтому дополнительная модель детектора речи для этой операции не запускается.

## Где лежит скрипт и как менять параметры

В исходном проекте скрипт находится в `desktop/speech/transcribe.py`.
В установленном приложении: `<папка установки>\resources\speech\transcribe.py`.
Исходные пути, значения параметров и описания полей заданы в
`desktop/speech-defaults.json`. Пользовательские значения сохраняются в
`speech-settings.json` внутри каталога пользовательских данных Electron.

Откройте **Настройки Whisper** под плеером. Измените поля и нажмите
**Сохранить параметры**. Кнопка **Распознать речь** также сохраняет текущие
значения перед запуском. Настройки восстанавливаются при повторном открытии
файла и после перезапуска приложения.

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| Язык записи | Русский (`ru`) | Можно выбрать другой язык или автоопределение. Язык должен поддерживаться выбранной моделью. |
| Режим | Распознавание | Дополнительно доступен перевод речи в английский текст. |
| Температура | 0 | При 0 используется beam search, при значении выше 0 — sampling. |
| Beam size | 5 | Число вариантов поиска при температуре 0, от 1 до 20. |
| Best of | 5 | Число вариантов при температуре выше 0, от 1 до 20. |
| Повышение температуры при повторе | Включено | При непрохождении порогов повторяет обработку с шагом 0,2, до температуры 1. |
| Предыдущий текст | Учитывается | Можно выключить использование контекста предыдущих фрагментов. |
| Patience | 1 | Регулирует поиск beam search при температуре 0. |
| Length penalty | 1 | Учёт длины результата, диапазон 0–1 для совместимости двух движков. |
| Порог отсутствия речи | 0,6 | Пропуск фрагмента без речи при низкой уверенности текста. |
| Порог уверенности текста | −1 | Слишком низкая средняя log probability запускает повтор, если включено повышение температуры. |
| Порог повторяемости | 2,4 | Проверка отношения сжатия текста при повторных попытках. |
| Потоки CPU | 0: автоматически, до 8 | Можно выбрать вручную от 1 до 32 потоков. |
| Вычисления | INT8 | Для faster-whisper можно выбрать Float32. Для моделей `.pt` используется Float32. |
| Подсказка | Пустая | Имена и термины для контекста; до 2000 символов. |

Дополнительные параметры находятся в раскрывающемся блоке. Интерфейс отключает
поля, которые не участвуют в выбранном режиме декодирования. VAD остаётся
выключенным и не зависит от этих полей. Изменение параметров во время активной
задачи заблокировано. Изменения применяются к следующему запуску.

## Что проверено при подготовке

Сборка веб-ресурсов и автоматические тесты проекта. Новые проверки охватывают
запуск настоящего процесса Python с тестовыми заменами библиотек моделей,
русский текст, пути с пробелами, OGG/WAV, CPU-настройки, передачу результата
в интерфейс, сохранение рядом с записью, защиту от перезаписи, отмену и ошибки.
Проверена конфигурация включения Python-скрипта в установщик.
Дополнительно проверены значения по умолчанию, миграция старых настроек,
сохранение и восстановление параметров, ограничения вводимых значений,
передача языка, температуры и остальных параметров обоим движкам,
различие имён `log_prob_threshold` и `logprob_threshold`, а также отмена
во время сохранения настроек до запуска Python.

Реальное распознавание вашей моделью Small и запуск на Windows здесь
не выполнялись: модель и ваш Python находятся на вашем компьютере.
Тестовые замены моделей не проверяют качество распознавания речи.
