# Omni 0.3 — изображения Markdown/IPYNB и редактирование CSV

Распакуйте архив в корень текущего проекта, рядом с `BUILD_WINDOWS.cmd`, с заменой файлов. В архиве только изменённые и новые файлы; EXE/APK нет.

Для обновления приложения запустите прежний скрипт сборки Windows или Android. Готовые веб-файлы уже обновлены; выполнять `npm run build` вручную не требуется.

## Изображения

Поддерживается стандартная разметка `![image1](seminar_data/2b827.png)`, включая Markdown-ячейки IPYNB и ссылки через `[image][reference]`. Картинки отображаются при чтении и в предпросмотре редактора.

На Windows оставьте картинки в папке рядом с исходным документом:

```text
папка документа/
  seminar.ipynb
  seminar_data/
    2b827.png
```

Открытие через кнопку, перетаскивание или Проводник сохраняет связь с папкой документа. Пути с пробелами и кириллицей поддерживаются. При сохранении копии Markdown/IPYNB ссылки остаются в исходном виде; переносите папку изображений вместе с экспортированным файлом.

На телефоне и в веб-версии нажмите **«Изображения»** и выберите нужные картинки. Доступ к соседним файлам здесь требуется предоставить через системное окно. Можно выбрать сразу несколько изображений; они сопоставляются по именам файлов. При одинаковых именах в разных папках автоматическое сопоставление по одному имени не применяется.

Если включено «Сохранять на устройстве», загруженные изображения сохраняются вместе с копией документа внутри приложения. Поддерживаются PNG, JPG/JPEG, GIF, WebP, BMP и AVIF. Внешние URL и выход за пределы папки документа не загружаются.

## CSV

Нажмите **«Редактировать»**, затем нужную ячейку. Значение вводится прямо в таблице, в том числе в полноэкранном режиме. Можно вставлять текст из буфера обмена.

- Enter — подтвердить значение и перейти на следующую строку.
- Tab / Shift+Tab — подтвердить и перейти к следующему / предыдущему столбцу.
- Shift+Enter — новая строка внутри значения.
- Esc в ячейке — отменить текущий неподтверждённый ввод.
- «Сохранить копию» — экспортировать CSV с исходным разделителем, в UTF-8 с BOM. Запятые, кавычки, переносы и ведущие нули сохраняются.

Отмена, повтор и переключение в просмотр используют текущий черновик. Исходный файл не перезаписывается.

Пояснение под «Сохранять на устройстве» удалено; сам переключатель остался.
