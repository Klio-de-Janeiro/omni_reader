Omni Reader — исправление мобильного редактора и PDF

Установка
1. Закройте проект и распакуйте архив в корень вашей актуальной версии Omni с заменой файлов.
2. Повторно соберите Android-приложение через BUILD_ANDROID.cmd. Используйте ранее настроенную release-сборку и прежний ключ подписи.
3. Установите полученный APK на телефон. Одной замены файлов на компьютере недостаточно для обновления уже установленного приложения.

Изменения
- Размер кисти и непрозрачность вынесены в отдельную панель под изображением.
- Панели рисования и изображение занимают отдельные области: переключение полного экрана не перекрывает кнопки и ползунки.
- Выход из полного экрана сохраняет сеанс редактирования, рисунок и историю отмены.
- Системная кнопка «Назад» Android сначала закрывает открытый диалог, затем полный экран, и только после этого запрашивает закрытие документа с обычным предупреждением о несохранённых изменениях.
- PDF увеличивается вокруг точки между пальцами без пересоздания страниц на каждом движении. Чёткость обновляется после паузы в жесте; прежнее изображение остаётся видимым до готовности нового.
- Слой текста PDF остаётся на месте при приближении; сохраняются выделение, поиск и режимы прокрутки/страниц.

Проверено
npm run build — успешно. npm test — 122 теста пройдены, без пропусков.
Проверены координаты масштабирования, сохранность экспортированных пикселей фотографии и порядок действий Android «Назад».
На физическом Android-устройстве не проверено. Браузерную проверку интерфейса выполнить не удалось: Chromium не запускается в среде проверки. APK в этот архив не включён.

Архив содержит только изменённые файлы и эту инструкцию. Он применяется поверх актуального проекта, включая предыдущие исправления.
