# Фактический статус проверки

04.10.2026. Восстановленная версия 0.3.0 для ноутбука, inline-редактор и оба режима просмотра. В поставку входят исходники и ресурсы; EXE/APK не включены.

## Выполнено

- Сборка локальных движков Office, PDF, XLSX и редакторов успешно завершена.
- **43 Node.js-теста прошли.** Сохранены проверки восьми форматов, повреждённых файлов, лимитов, CSV/Unicode, таблиц, истории и экспорта.
- Экспорт DOCX/PPTX сохраняет четыре вида оформления, Unicode, переносы, табуляцию и незатронутые части пакета. Проверены частичное оформление и выключение оформления, исходные шрифты/цвета, новые абзацы/страницы, слайды/разделы, отмена/повтор структуры и текста добавленного слайда, ввод в пустой DOCX.
- Реальные docx-preview и pptx-renderer проверены в JSDOM: привязка editable-текста, ввод/оформление, смена режимов, масштаб, повторная отрисовка, сохранение состояния. Выгрузка слайда сохраняет незавершённый ввод.
- Панель редактора проверена через сообщения sandbox: начальная прокрутка, выбор режима/страницы, добавление слайда и сохранение выбранного режима после перестроения. Сохранение дожидается последних правок.
- PDF-контроллер проверен на управляемом PDF-объекте из 80 страниц: не более четырёх canvas в прокрутке, одна видимая страница в постраничном режиме, сохранение страницы/масштаба, поиск, обновление номера при прокрутке, отмена отрисовки и очистка памяти. Реальная растеризация PDF этим тестом не проверяется.
- Независимое чтение экспортов: python-docx, python-pptx, openpyxl, pypdf, Python csv/wave. Проверены текст, четыре вида оформления и их выключение, новая страница DOCX, четыре слайда PPTX, значения/формулы XLSX, поворот PDF и аудиокадры WAV. Экспорт после смены режимов также прочитан.
- Готовые ресурсы синхронизированы с Windows/Android. Синтаксис JS, XML Android и отсутствие Git-источников в desktop lock-файле проверены. Целостность архива и наличие файлов запуска/сборки проверены.

## Границы проверки

- Chromium в этой среде завершается с SIGSEGV до открытия приложения. Полный браузерный сценарий не прошёл; JSDOM не заменяет визуальную приёмку, настоящий ввод и проверку геометрии.
- Запуск CMD, Electron, установка, файловые ассоциации и системный экспорт непосредственно на Windows не проверены. Для этой поставки установщик не собирался, поскольку запрошен проект без EXE.
- APK и интерфейс на телефоне не проверены. Пиксельный экспорт JPG/PNG, сложные Office-документы и очень большие файлы требуют практической проверки.
- Предупреждения npm audit не устранялись принудительным обновлением всех транзитивных зависимостей.

## Повторение

npm ci, npm run build, npm test, py tests/independent_readers.py, npm run native:sync.

На Windows запустите START_WEB.cmd или START_WINDOWS.cmd. Проверьте DOCX/PPTX: щёлкните текст, введите правку, выделите часть и примените B/I/U/S; переключите режим и масштаб, проверьте новые страницы/слайды/разделы и undo/redo. Сохраните копию и откройте её в Word/PowerPoint. В PDF проверьте прокрутку по умолчанию, переключение, поиск и навигацию. Затем проверьте остальные форматы, расширенный режим и системный экспорт.
