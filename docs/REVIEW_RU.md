Браузерный сценарий проверяет просмотр PDF/DOCX/PPTX/WAV/JPG/PNG/XLSX/CSV,
редактирование и сохранение копий тех же форматов, повторное чтение экспортированных
байтов, отсутствие необработанных исключений и горизонтального переполнения при ширине 390 px.
Проверки Whisper используют настоящий Python-процесс и заглушки моделей;
качество распознавания настоящей моделью этим набором не измеряется.

Локальные результаты сборок:

```text
release/windows/Omni-Reader-0.3.0-Windows-Setup.exe
android/app/build/outputs/apk/debug/app-debug.apk
```

Бинарные сборки, ключи подписи, зависимости и временные результаты не публикуются
в исходном репозитории. Ручной workflow Native installers сохраняет EXE/APK
как артефакты GitHub Actions.

## Исправления

- Исправлена чистая установка тестов конвертации PDF: добавлена зафиксированная
  зависимость `sax`, необходимая vendored XML-парсеру при прямом импорте из Node.js.
- Сохранено ранее начатое обновление PDF → XLSX/CSV, его исходники, документация и тесты.
- Обновлены Electron **42.1.0 → 42.11.15** и electron-builder **26.0.12 → 26.15.3**.
  Подготовка Windows-инструментов адаптирована к новым путям rcedit/signtool;
  проверка SHA-512 и извлечение без macOS-ссылок сохранены. Публикация релиза
  при локальной сборке явно отключена.
- `7zip-bin` объявлен прямой зависимостью сборки вместо неявной транзитивной.
- Canvas-бэкенд добавлен в devDependencies: пиксельные проверки больше не зависят
  от внешнего окружения Codex и не пропускаются на этой машине.
- Исправлены платформенные ожидания путей в Windows-тесте, недетерминированное
  ожидание жестов и тестовые заглушки FFmpeg/taskkill.
- Браузерные тесты обновлены под текущие полноэкранные элементы управления,
  навигацию PDF и инструмент обрезки. Удалён конфликтующий init-скрипт Playwright
  для блокировки Service Worker в непрозрачных sandbox-iframe Office;
  проверка отсутствия браузерных ошибок сохранена.
- В обязательный набор включены тесты инструментов Windows.
- Первый запуск CI на Ubuntu выявил отсутствующий executable bit у `7zip-bin`;
  тестовая подготовка восстанавливает права перед запуском упакованного инструмента.
- Добавлены README со снимком интерфейса, CONTRIBUTING, шаблоны issue/PR,
  автоматические проверки на Ubuntu/Windows и установка desktop-зависимостей
  в существующем workflow сборки.
- Из отслеживания Git удалены настройки IDE, Python-байткод и устаревший JSON
  результата тестов; локальные файлы сохранены. Расширен `.gitignore`.

## Зависимости и оставшиеся ограничения

На дату проверки `npm audit` сообщает:

| Набор | Critical | High | Moderate |
| --- | --- | --- | --- |
| Корневой проект | 0 | 0 | 0 |
| Инструменты desktop | 0 | 0 | 8 |

Оставшиеся 8 записей относятся к одной цепочке dev-зависимостей
`sprintf-js → roarr → global-agent → @electron/get → electron-builder`.
Причина — [GHSA-hp3w-g68c-fv3c](https://github.com/advisories/GHSA-hp3w-g68c-fv3c),
отказ в обслуживании через форматную строку. На момент проверки опубликованная
версия `sprintf-js` — 1.1.3, исправленного релиза нет. Автоматическое предложение
npm откатить сборщик до 26.5.0 не применялось. Эти пакеты используются при
разработке/сборке и не входят в зависимости приложения в упакованном ASAR.

- После обновления electron-builder пути к инструментам с `&` и другими командными
  спецсимволами отклоняются самим сборщиком; используйте обычный путь к проекту.
- Сборка Android использует устаревающий API; компиляция проходит, но предупреждение
  требует отдельного обновления Android-оболочки.
- Настоящая установка EXE, ассоциации файлов Windows, Android на телефоне,
  настоящие Whisper-модели, очень большие и сложные пользовательские документы
  не проверялись автоматически.
- PDF.js в Node-тестах предупреждает о загрузке стандартного шрифта через `file:`;
  извлечение и повторное чтение экспортов проходят. Браузерный сценарий проходит.
- Сохранённые исходники и тесты отключённых `recorder`/`voice-*` не являются
  действующей функциональностью версии 0.3.0. Попытка запуска всех исторических
  `tests/*.test.mjs` зависает в старом голосовом наборе; для приёмки используйте `npm test`.
- Лицензия собственного кода не назначалась без решения владельца.

Команды для повторения находятся в [README.md](../README.md).
