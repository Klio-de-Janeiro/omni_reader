# ТЗ Omni Reader Native 0.3.0

Дата: 04.10.2026. Заменяет первоначальное ТЗ на PWA в части формата поставки и интерфейса.

## Цель и поставка

Личное устанавливаемое приложение для Android и Windows. Итоговая поставка должна включать устанавливаемый Android APK, Windows EXE-установщик и исходники. В текущем архиве выполнена реализация исходного проекта и сборочных сценариев; создание APK/EXE и проверка на целевых ОС остаются незавершёнными из-за ограничений среды.

Android: Java Activity + системный WebView с ресурсами внутри APK. Windows: Electron с локальным протоколом и ресурсами внутри приложения. Общий движок просмотра на JavaScript. Никакой зависимости установленного приложения от опубликованного сайта, сервера обработки файлов или регистрации.

## Интерфейс

Чёрный фон `#020611`, яркий синий `#0989FF`, голубое свечение, светлый читаемый текст, плавные округления 12–28 px. Рабочий просмотрщик доступен сразу. Белая подложка страницы документа сохраняется для корректного просмотра оригинала; оболочка тёмная.

## Форматы и взаимодействие

| Формат | Возможности | Ограничения |
|---|---|---|
| PDF | Постраничный canvas + text layer, выделение и копирование, поиск, ввод страницы, масштаб | Текст только при наличии текстового слоя; редактор поворачивает/удаляет страницы, без замены текста и OCR |
| DOCX | Текст, таблицы и изображения, выделение/копирование, поиск, переходы и масштаб | Вёрстка и автоматические разрывы могут отличаться от Word |
| PPTX | Слайды, выделение текста, поиск с переходом, номер слайда, масштаб | Статический предпросмотр, без анимаций и макросов |
| XLSX | Листы, значения, текст формул и сохранённые результаты; диапазоны, копирование TSV, адрес ячейки, поиск | Без пересчёта, оформления, диаграмм и объединения ячеек |
| CSV | Разделители и кодировки, интерактивная таблица, диапазоны, поиск и переход | UTF-8, Windows-1251, UTF-16 LE с BOM; до 500 тыс. ячеек |
| WAV | Play/pause, скорость, перемотка ±10 с, ввод времени | Поддержка кодеков зависит от движка; базовый профиль PCM |
| JPG/PNG | Масштаб, поворот, прокрутка | Текст внутри изображения не выделяется без OCR |

## Редактирование 0.3

Операции реализуются поверх отдельной модели редактора. Полная спецификация управления и ограничений — `EDITING_RU.md`.

| Формат | Обязательные операции текущего этапа |
|---|---|
| XLSX | Выбор листа/адреса, изменение и очистка ячейки, явный тип текст/число/булево/формула, добавление новых ячеек |
| CSV | Изменение текстового значения, создание ячейки по адресу, экспорт UTF-8 с BOM |
| DOCX/PPTX | Поиск существующего текстового фрагмента, изменение его текста с сохранением свойств фрагмента |
| PDF | Поворот на 90°, исключение и возврат страницы; запрет удаления последней страницы |
| JPG/PNG | Обрезка по исходным координатам и поворот на 90°, реальный экспорт пикселей |
| WAV | Обрезка в секундах и громкость −24…+24 dB для RIFF PCM16 |

Общие операции: отмена/повтор до 100 шагов, предпросмотр, признак несохранённых изменений, подтверждение выхода из изменённого черновика. «Сохранить копию» применяет активное поле, формирует новый файл, проверяет его тип/размер, добавляет в список, сохраняет локально при включённом переключателе и запускает системный экспорт. Ошибка записи локальной копии оставляет черновик открытым. Отмена системного экспорта не удаляет копию из приложения.

Для XLSX после изменения очищаются кэшированные значения формул и calcChain с соответствующими связями; книга запрашивает полный пересчёт во внешнем приложении. Защищённые листы, общие/массивные формулы и неякорные объединённые ячейки не редактируются. Изменять стили и структуру Office, заменять существующий текст PDF, обрабатывать OCR, автоматически сохранять черновики и восстанавливать историю между перезапусками — следующие этапы.

## ОС и интеграция

- Android: системный ACTION_OPEN_DOCUMENT, ACTION_VIEW для поддерживаемых MIME, ACTION_CREATE_DOCUMENT при экспорте; без широкого доступа к хранилищу. Минимальная ОС Android 8, актуальный WebView — требование для проверки совместимости.
- Android bridge: команды через onJsPrompt только с точного URL главного документа. Изолированные Office frames не получают доступ к нативным операциям.
- Windows: BrowserWindow, sandbox, contextIsolation, nodeIntegration выключен. IPC ограничен главным фреймом и небольшим API; чтение пользовательских путей из renderer не предоставляется.
- Windows: NSIS per-user установка, ярлык и ассоциации расширений. Процесс сборки не подписывает EXE сертификатом издателя.
- При смене документа старый просмотр уничтожается; копии файлов хранятся отдельно от оригиналов в локальном хранилище движка.

## Данные и ресурсы

Сохранение — IndexedDB, отдельно на каждом устройстве. До 20 сохранённых файлов/256 МиБ. Приложение не является резервной копией; удаление приложения или его данных удалит сохранённые копии.

Для таблиц хранится модель ячеек. В DOM выводится не более 100 × 30 ячеек за один раз. Выделение может пересекать окна просмотра; копирование ограничено 100 тыс. ячеек за операцию. Поиск показывает до 1000 совпадений на листе.

Файлы проверяются по размеру и сигнатуре; OOXML — дополнительно по каталогу ZIP. Внешние источники Office заблокированы, формулы таблиц не выполняются. Это базовые ограничения, а не гарантия устойчивости против любых специально подготовленных документов. Нужны отдельный аудит, fuzzing и замеры памяти на физических устройствах.

## Сборка

Android: JDK 17+, AGP 8.9.2, Gradle 8.11.1, compile/target SDK 35, Build-Tools 35.0.0. Локальная первая сборка создаёт подписанный debug APK. Перед магазином нужны собственная release-подпись, политика обновления, проверка актуальных требований target SDK и дополнительные испытания.

Windows: Node 22+ для разработчика, Electron 42.1.0, electron-builder 26.0.12, NSIS x64. После успешной установки пользователю Node и npm не нужны. Отдельный desktop lockfile должен быть сохранён после первой успешной установки зависимостей; сейчас транзитивные зависимости desktop не зафиксированы.

## Приёмка до объявления готового релиза

1. Успешно собрать APK и EXE на целевых toolchain, сохранить хеши и журналы.
2. Установить APK на физический Android и EXE в чистую Windows; проверить запуск без интернета и без dev-сервера.
3. Открыть 8 форматов из приложения и через ОС, проверить повреждённые файлы.
4. Выделить/скопировать PDF/DOCX/PPTX, найти текст и перейти к нужной странице/слайду.
5. XLSX: 2 листа, дата, процент, формула, ячейка B250, диапазон A1:C20. CSV: кавычки, переносы, UTF-8 и Windows-1251.
6. WAV: перемотка к заданному времени; картинки: масштаб/поворот.
7. Перезапустить приложение и открыть локальную сохранённую копию; экспортировать оригинал и сравнить SHA-256.
8. Изменить и экспортировать каждый формат; повторно открыть в Omni и независимом приложении. Проверить сохранение оригинала, отмену/повтор, отмену выхода и системного экспорта, ошибку хранилища. Проверить пиксели обрезки/поворота JPG/PNG, каналы и длительность WAV.
9. Проверить мобильную ширину, системное выделение долгим нажатием, поворот экрана, back, отмену диалогов.

Статус этих проверок отражён отдельно в VALIDATION_RU.md; наличие кода не считается успешной приёмкой.
