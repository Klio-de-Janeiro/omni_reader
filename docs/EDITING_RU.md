# Редактирование в Omni 0.3.0

DOCX/PPTX: нажмите **Редактировать**, затем щёлкните текст прямо на странице/слайде. Дополнительное окно ввода не открывается. Для остальных форматов сохранён прежний редактор с кнопками **Применить** и **Предпросмотр**.

PDF/DOCX/PPTX по умолчанию открываются с **Прокруткой**. Переключатель **Режим** показывает все страницы подряд либо одну страницу. Он доступен в просмотре, inline-редакторе и предпросмотре PDF. Текущая страница, масштаб и внесённый текст сохраняются; поиск и навигация работают в обоих режимах. Новый открытый файл снова использует прокрутку.

**На весь экран** расширяет рабочую область с отступами для управления. **Файлы** скрывает список. Ctrl+Shift+F переключает расширенный режим, Esc выходит из него.

## Что можно менять

| Формат | Возможности |
|---|---|
| DOCX | Текст обычных абзацев, B/I/U/S, спецсимволы, новые абзацы и страницы |
| PPTX | Текст обычных абзацев слайдов, B/I/U/S, спецсимволы, новые слайды и разделы |
| XLSX | Текст, числа, TRUE/FALSE, формулы, очистка и новые ячейки по адресу; формулы здесь не пересчитываются |
| CSV | Текст существующих/новых ячеек; копия — UTF-8 с BOM и исходным разделителем |
| PDF | Поворот на 90°, удаление и возврат страниц; в копии остаётся хотя бы одна страница |
| JPG/PNG | Прямоугольная обрезка в исходных пикселях и поворот |
| WAV | Обрезка по времени и усиление −24…+24 dB для PCM 16-bit |

## DOCX/PPTX

Выделите текст в одном абзаце и нажмите B, I, U или S. Ω вставляет спецсимвол. При отсутствии выделения оформление действует на следующий ввод. Вставка из буфера переносит обычный текст. Enter вставляет перенос строки в текущий абзац.

+ Абзац / + Страница вставляет после выбранного абзаца DOCX. + Слайд / + Раздел вставляет после текущего слайда PPTX. Раздел — группа слайдов, сохраняемая в структуре презентации.

Ctrl+B/I/U — жирный/курсив/подчёркивание; Ctrl+Shift+X — зачёркивание. Ctrl+Z/Y и Ctrl+Shift+Z — отмена/повтор. Ctrl+S — копия. Ctrl+Enter — новая страница DOCX/слайд PPTX; Ctrl+Alt+N — слайд PPTX; Ctrl+Shift+Enter — раздел PPTX.

Шрифты, изображения, формы, положение объектов и анимации не редактируются. Длинный текст может выйти за исходную рамку PowerPoint. Сложные абзацы с полями, ссылками, рисунками, встроенными объектами или разделением между страницами доступны для чтения. Основной текст DOCX и текстовые блоки PPTX редактируются; колонтитулы и заметки не являются отдельными инструментами редактора. Защищённые/подписанные Office-файлы отклоняются.

## Сохранение и история

Сохранить копию дожидается текста в активном поле. Завершите IME-ввод перед сохранением или переключением. Формат копии совпадает с исходным; конвертация между форматами не добавлялась.

Копия получает имя вида имя-edited-1.ext и остаётся в списке, даже если отменён системный диалог экспорта. При включённом «Сохранять на устройстве» копия записывается в локальное хранилище до экспорта. При выключенном переключателе она живёт в памяти текущего сеанса. Если места недостаточно, редактор сохраняет открытый черновик и сообщает ошибку.

Отмена/повтор: до 100 действий. Последовательный ввод группируется; новая правка после отмены очищает ветку повтора. При закрытии с правками предлагается остаться либо закрыть без сохранения. Автосохранение черновиков не реализовано; аварийное завершение теряет несохранённый текст. После сохранения открывается копия в режиме просмотра.

## Ограничения других форматов

XLSX: стили/рисунки/диаграммы/объединение ячеек не воспроизводятся полностью. Изменённая копия запрашивает пересчёт в Excel/LibreOffice, устаревшие кэшированные результаты формул удаляются. Защищённые листы и внутренние ячейки объединённых/массивных диапазонов не редактируются.

PDF: замена текста, OCR и сохранение цифровой подписи не поддерживаются. Поворот/удаление выполняет PDF-Lib.

Изображения: JPEG кодируется повторно, EXIF и другие метаданные в копию не переносятся. WAV: метаданные не переносятся, пики при усилении ограничиваются. Для изображений, сканов и звука текстовое форматирование неприменимо.
