# LaTeX в Omni

Откройте `.tex` обычной кнопкой открытия файлов. Редактор запускается сразу;
устанавливать компилятор для правки текста не требуется.

## Работа с документом

- **.tex | PDF** — исходный текст слева, результат справа. Границу можно перетаскивать;
  с клавиатуры выберите разделитель Tab и меняйте ширину стрелками.
- **.tex** — только исходник; **PDF** — только последняя успешная сборка.
- **Компилировать / Ctrl+Enter** — собрать текущий черновик без предварительного сохранения.
- **Автокомпиляция** — пересобирать после паузы в наборе. По умолчанию выключена.
- **Остановить** — отменить текущую сборку и её дочерние процессы.
- **Сохранить .tex / Ctrl+S** — записать изменения в исходный файл. Редактор остаётся открытым.
- **Копия .tex** — сохранить отдельную копию стандартным способом Omni.
- **Скачать PDF** — экспортировать последнюю успешную сборку.

Текст и история правок сохраняются при смене режима. Если сборка завершилась ошибкой,
предыдущий PDF остаётся виден. Пометка «PDF устарел» означает, что после этой сборки
исходник или дополнительные файлы изменились. Ошибки находятся в журнале под рабочей
областью; нажмите сообщение со строкой, чтобы перейти к нему в исходнике.

В узком окне разделённый режим располагает панели друг под другом. Можно выбрать
только текст или только PDF, чтобы отдать документу всю доступную область.

## Установка компилятора

В папке исходного проекта выполните:

```sh
npm ci
npm run latex:setup
```

Скрипт скачивает официальный **Tectonic 0.17.0**, проверяет SHA-256 и помещает
исполняемый файл в `desktop/latex-runtime/`. Системная установка TeX Live/MiKTeX
не требуется. Поддерживаются Windows x64, Linux x64 и macOS x64/arm64.
Собственный Tectonic можно указать через переменную окружения `OMNI_TECTONIC_PATH`.

Запустите `START_WINDOWS.cmd` либо `START_WEB.cmd` (или `npm start`). В Windows
компилятор вызывается приложением, а в браузере — локальным сервером Omni.
Обычная статическая публикация `dist/` не может запускать локальный компилятор.
Windows-установщик, собранный через `BUILD_WINDOWS.cmd`, уже содержит движок.

При первой компиляции Tectonic скачивает формат, пакеты и шрифты. Это может занять
несколько минут; последующие сборки используют кэш. Новому пакету снова может
потребоваться сеть. Пакеты запрашиваются у сервера Tectonic; исходный текст и файлы
проекта не отправляются на удалённый сервис компиляции.

Компилируйте только доверенные проекты и отметьте соответствующий флажок перед
первой сборкой в редакторе. Shell escape отключён через `--untrusted`, однако это
не изоляция файловой системы: команды TeX могут обращаться к локальным файлам.
Автоматическое исполнение при открытии документа отключено.

## Сохранение

На Windows файл, открытый с диска, сохраняется по исходному пути. Если документ
создан из локальной копии Omni, сначала откроется системный диалог выбора `.tex`;
последующие сохранения используют выбранное место. Если другая программа изменила
исходник, Omni откажется его затирать: откройте файл заново или сохраните копию.

В браузерах с File System Access API (например, Chromium на компьютере) первый
Ctrl+S предлагает выбрать файл и разрешить запись. Для замены оригинала выберите
тот же `.tex`. При последующих сохранениях используется это разрешение. В браузерах
без этого API и на Android доступна кнопка **Копия .tex**.

UTF-8/UTF-16 BOM и окончания строк сохраняются. Старые Windows-кодировки при
редактировании переводятся в UTF-8. Скомпилированный PDF не заменяет исходник.

## Файлы проекта

При открытии `.tex` с диска в Windows автоматически подхватываются локальные файлы,
на которые явно ссылаются `\input`, `\include`, `\includegraphics`, `\bibliography`,
`\addbibresource`, `\usepackage`, `\documentclass`, включая вложенные главы.
Ссылки должны быть обычными относительными именами внутри папки исходника.

Кнопка **Файлы проекта** позволяет выбрать папку с главами, изображениями,
библиографией и шрифтами — в том числе в браузере. Основным остаётся открытый `.tex`;
его черновик имеет приоритет над копией в выбранной папке. При изменении дополнительных
файлов на диске выберите папку заново, чтобы обновить снимок проекта.
Для вычисляемых имён и сложных путей используйте явный выбор папки.

## Кириллица

Tectonic использует XeTeX. Для Unicode удобно использовать `fontspec` со шрифтом,
содержащим кириллицу. Например, на Windows:

```tex
\documentclass{article}
\usepackage{fontspec}
\setmainfont{Arial}
\usepackage[english,russian]{babel}
\begin{document}
Привет, мир! Формула: $E=mc^2$.
\end{document}
```

На другом компьютере выберите установленный шрифт либо добавьте собственный файл
шрифта в проект. Поддерживается XeTeX-совместимый LaTeX; команды, зависящие только
от pdfLaTeX/LuaLaTeX, shell escape, внешних программ или `minted`, могут требовать
изменения документа. Выбор других движков и облачный сервис Overleaf не подключены.

## Лимиты и проверки

Исходник: 8 МиБ; дополнительные файлы: 256 и 64 МиБ суммарно; PDF: 50 МиБ;
журнал: 5 МиБ; одна сборка: до 5 минут. При ошибке или отмене частичный PDF не
показывается. На Android полноценный локальный движок пока не включён.

Проверки от 18.10.2026: **187 Node-тестов** без пропусков, браузерный сценарий
редактора с настоящим Tectonic, реальная компиляция кириллицы и `\input` с
независимым повторным чтением PDF.

```sh
npm test
npm run test:e2e:latex
# Настоящий движок после latex:setup, с сетью для новых пакетов:
# PowerShell: $env:OMNI_REAL_LATEX='1'; npm run test:e2e:latex
```

Документация движка: [CLI](https://tectonic-typesetting.github.io/book/latest/v2cli/compile.html),
[Unicode](https://tectonic-typesetting.github.io/book/latest/getting-started/unicode.html).
