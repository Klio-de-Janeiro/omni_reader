# Диктофон Omni: обновление для Windows

Архив накладывается на текущий проект Omni с уже установленным патчем
диктофона Silero. Это изменённые и новые исходные файлы, не полный проект.
Готовых EXE и моделей в архиве нет.

## Установка

1. Остановите запись и полностью закройте Omni, в том числе через значок
   в трее. Распакуйте архив в корень проекта, где находится
   `BUILD_WINDOWS.cmd`, согласившись на замену файлов.
2. Откройте PowerShell в этой папке и обновите окружение диктофона:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\SETUP_VOICE_WINDOWS.ps1
   ```

   Установка добавит NumPy и SciPy для очистки WAV, сохранит отдельное
   окружение `C:\Users\User\Desktop\omni_voice_env` и установленную фиксацию
   Torch CPU 2.8.0. Окружение Whisper не изменяется. Сначала должен успешно
   завершиться самотест Python/Silero; ошибка DLL означает, что окружение
   ещё не готово к записи.
3. Запустите сборку:

   ```powershell
   .\Build_windows
   ```

   В Windows эта команда запускает `BUILD_WINDOWS.cmd`. Требуются Node.js
   22.12 или новее и npm. Скрипт проверяет наличие файлов диктофона,
   синхронизирует интерфейс, устанавливает зависимости Electron и создаёт
   `release\windows\Omni-Reader-0.3.0-Windows-Setup.exe`.
   Python-скрипты диктофона, включая очистку звука, входят в установщик.
   Само окружение Python остаётся локальным и не упаковывается в EXE.

## Управление

- Нижняя кнопка с микрофоном **Начать запись** сразу включает диктофон.
  Повторное нажатие **Остановить запись** завершает запись и сохраняет
  последний фрагмент. Состояние видно под кнопкой и в индикаторе записи.
- Вместо списка открытых файлов в боковой панели находится кнопка
  **Настройки микрофона**. Кнопка открытия файлов сохранена.
- Паузы **3 / 5 / 8 / 12 секунд** применяются сразу, даже при записи.
  Можно задать свою паузу от 200 до 12000 мс. Новый профиль использует 5 с;
  ранее сохранённое значение не сбрасывается.
- В настройках доступны выбор микрофона, папки и Python, порог речи,
  лимит места, предзапись 0–2000 мс и длина фрагмента 30–600 с.
  Эти параметры сохраняются кнопкой **Сохранить настройки** и меняются
  при остановленном диктофоне. Предзапись по умолчанию — 1024 мс,
  максимум фрагмента — 10 минут.
- **Создавать очищенную копию WAV** включено по умолчанию: фильтр гула
  ниже 70 Гц и мягкое подавление шума по участкам тишины, как в приложенном
  телефонном диктофоне. Без достаточного участка тишины работает только
  фильтр гула. **Выравнивать громкость** — отдельная опция для копии,
  усиление ограничено +6 дБ.
- Оригиналы WAV и JSON сохраняются в `sessions\<сеанс>`, копии — рядом
  в подпапке `clean`. При ошибке или перегрузке очистки оригинал остаётся,
  а в настройках появляется сообщение. Длительность файлов отображается
  для текущего сеанса; объём включает имеющиеся записи в папке.
- Закрытие панели настроек не останавливает запись. Закрытие окна Omni
  во время записи сворачивает его в трей; пункт **Выйти из Omni** завершает
  запись. Завершение очистки после выключения микрофона отображается
  отдельно. Запись начинается только по нажатию кнопки.

Silero определяет наличие речи, а не личность говорящего. Распознавание
команд Qwen и автоматическая отправка текста в Whisper в этот патч
не входят. Телефонный интерфейс этим обновлением не изменяется.

## Проверено

- Общие тесты проекта: 156 успешно; после финальных изменений повторно
  проверены тесты диктофона.
- На реальных PCM/WAV проверены сегментация, сохранение оригинала,
  очистка, ограничение усиления, квота, обработка ошибок и сохранение
  оставшихся в очереди аудиоблоков при остановке.
- Сборка веб-ресурсов `npm run build` выполнена без создания EXE.
- Windows, PowerShell и физический микрофон в среде проверки недоступны.
  Проверки интерфейса выполнены через DOM; запуск браузерной визуальной
  проверки был заблокирован сбоем Chromium в этой среде.
