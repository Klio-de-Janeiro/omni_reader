# Исправление Windows-сборки Omni 0.3

Распакуйте этот архив **в корень существующего проекта**, рядом с `BUILD_WINDOWS.cmd`, с заменой файлов. Добавьте папки `scripts` и `tests`, если их ещё нет.

Затем запустите обычную команду:

```powershell
.\BUILD_WINDOWS.cmd
```

Причина ошибки: electron-builder распаковывает общий архив `winCodeSign-2.6.0`, содержащий символические ссылки библиотек macOS. Windows без разрешения на создание таких ссылок останавливает распаковку.

Теперь `desktop/package.json` запускает `scripts/build-windows.mjs`. Скрипт проверяет SHA-512 официального архива, распаковывает его без папок macOS/Linux и передаёт electron-builder локальный кэш `.tools/electron-builder-windows`. Повторная сборка использует проверенный кэш; неполный или повреждённый кэш создаётся заново. Права администратора для этого исправления не нужны.

Редактирование ресурсов EXE остаётся включённым: иконка и данные версии сохраняются. Интерфейс и функции приложения не менялись. Удалять прежний системный кэш electron-builder не требуется.

Результат успешной сборки: `release/windows/Omni-Reader-0.3.0-Windows-Setup.exe`.

Проверено: распаковка настоящего официального архива, совместимость подготовленного кэша с закреплённым electron-builder, повторное использование и восстановление кэша, отказ при неверной контрольной сумме. Регрессионные проверки: `node --test tests/windows-build-tools.test.mjs tests/desktop-windows.test.mjs` после установки зависимостей desktop.

В этом архиве нет скомпилированного приложения. Сам установщик Windows в среде Linux не собирался.
