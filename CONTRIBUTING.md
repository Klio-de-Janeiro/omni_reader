# Внесение изменений

Создайте отдельную ветку, внесите небольшое целевое изменение и откройте pull request.
В описании укажите проблему, результат и выполненные проверки.

Перед отправкой выполните команды из раздела «Проверки» в [README.md](README.md).
Если меняются браузерные движки или ресурсы, запустите `npm run build` и включите
обновлённые ресурсы `dist/` в тот же коммит. Не удаляйте `dist/`: часть исходников
интерфейса находится непосредственно в этом каталоге.

`npm test` проверяет текущие функции и инструменты Windows. Тесты `recorder` и
`voice-*`, а также Python-тесты `voice_*` относятся к отключённому голосовому помощнику
и не входят в обязательный набор текущей версии.

Не добавляйте ключи подписи, токены, `.env`, модели распознавания, локальные
окружения, зависимости, установщики и пользовательские документы.
Для примеров ошибок используйте обезличенный минимальный файл.

Не меняйте лицензии сторонних библиотек и не назначайте лицензию собственному
коду без решения владельца проекта.
