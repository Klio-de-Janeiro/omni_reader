# Установка первого этапа голосового помощника

Это патч поверх текущего проекта с настройками Whisper. В архиве только изменённые
и новые файлы; готового EXE, моделей и Python-окружения нет.

1. Распакуйте архив в корень проекта Omni с заменой совпадающих файлов.
2. В PowerShell из этой папки выполните ` .\SETUP_VOICE_WINDOWS.ps1 `.
   Скрипт использует ваш Python
   `C:\Users\User\Desktop\whisper_env\Scripts\python.exe`, но создаёт отдельное
   окружение `C:\Users\User\Desktop\omni_voice_env` для диктофона. Существующая
   установка Whisper не изменяется. Нужен интернет для установки ONNX Runtime,
   sounddevice и пакета с моделью Silero. Torch диктофону больше не требуется.
   Установка может занять несколько минут.
   Если политика PowerShell запрещает локальный скрипт, запустите его один раз:
   `powershell -NoProfile -ExecutionPolicy Bypass -File .\SETUP_VOICE_WINDOWS.ps1`.
3. Запустите проект обычной командой ` .\START_WINDOWS.cmd `.
   Для обновления установленного приложения позже используйте `BUILD_WINDOWS.cmd`.
4. В боковой панели откройте **Настройки микрофона**. Проверьте Python:
   `C:\Users\User\Desktop\omni_voice_env\Scripts\python.exe`.
   Путь подхватывается автоматически, если окружение создано в стандартной папке;
   иначе укажите его кнопкой **Выбрать Python**.
5. Нажмите **Обновить микрофоны**, выберите нужный и **Начать запись**.
   Если Windows запрещает запись, разрешите доступ настольным приложениям к
   микрофону в настройках конфиденциальности Windows.
6. Произнесите фразу, подождите паузу. **Открыть папку записей** показывает WAV/JSON.
   WAV можно открыть в Omni и распознать существующей кнопкой Whisper вручную.

Для другого базового Python: ` .\SETUP_VOICE_WINDOWS.ps1 -BasePython "D:\Python\python.exe" `.
Параметр `-VoiceEnvironment` меняет папку отдельного окружения.
Поддерживаются Python 3.10–3.13 x64. Для исправления прежнего таймаута запуска
и диагностики окружения см. `VOICE_STARTUP_FIX_RU.md`.

**Управление:** закрытие панели не останавливает запись. При работающем диктофоне
закрытие окна сворачивает его в трей и сохраняет открытый документ. Значок Omni
позволяет открыть окно, остановить микрофон или полностью выйти. Остановка
последнего скрытого окна возвращает окно на экран. После полного выхода/сна
запись не возобновляется самостоятельно.

Автоматическое распознавание фрагментов добавлено в этапе 2 (`VOICE_STAGE2_RU.md`).
**Пока не реализовано:** узнавание вашего голоса, Qwen, создание и доставка
напоминаний, учёт прогресса. Полное ТЗ и
критерии следующих этапов находятся в `VOICE_ASSISTANT_SPEC_RU.md`.

Параметры сохраняются в `recorder-settings.json` в каталоге данных Omni;
точная папка аудио отображается в интерфейсе. Лимит места не удаляет старые записи:
при заполнении запись останавливается. Записи первого этапа — непроверенные
кандидаты для будущего датасета, а не подтверждённые образцы только вашего голоса.
