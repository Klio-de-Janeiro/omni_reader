ЗНАЧОК OMNI НА ПАНЕЛИ ЗАДАЧ WINDOWS

1. Закройте все окна Omni.
2. Распакуйте ZIP в корень текущего проекта с заменой файлов. Это дополнение
   к Omni_0.3_Notebooks_Text_Mobile_Patch.zip с поддержкой omni.png.
3. Положите свою картинку omni.png в корень проекта рядом с BUILD_WINDOWS.cmd.
   Рекомендуется квадратная PNG 512 x 512 или 1024 x 1024 с прозрачностью.
4. Запустите BUILD_WINDOWS.cmd и установите полученную новую версию.
5. Открепите старый значок Omni/Electron от панели задач. Запустите установленный
   Omni Reader через меню «Пуск» и закрепите его заново.
   Для постоянного закрепления используйте установленную версию, а не запуск
   среды разработки через START_WINDOWS.cmd.

Причина: signAndEditExecutable: false отключал вставку icon.ico в EXE.
Исправлено: вставка ресурсов EXE включена, Windows AppUserModelID совпадает
с идентификатором установленного приложения dev.klio.omni.
Генерация PNG/ICO из omni.png уже включена в предыдущий патч.

Проверено: конфигурация прошла схему electron-builder 26.0.12;
тест маршрутизации файлов и Windows AppUserModelID прошёл.
Установщик и итоговая иконка на Windows здесь не проверялись.
В этом ZIP нет EXE или APK — только файлы для замены.
