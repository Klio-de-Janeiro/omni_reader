# PDF → Excel и CSV

Распакуйте патч в корень проекта Omni Reader с заменой файлов, сохраняя
структуру папок. Готового EXE в архиве нет.

Запуск из исходников: `START_WINDOWS.cmd`. Для обновления установленного
приложения выполните `BUILD_WINDOWS.cmd` и установите полученный установщик.
Для Android пересоберите APK обычным скриптом проекта. В браузере обновите
страницу после установки патча, чтобы загрузился новый офлайн-кэш.

Откройте PDF и выберите рядом с «Редактировать»:

- **Конвертировать → В Excel (.xlsx)**;
- **Конвертировать → В CSV**.

Меню доступно также в полноэкранном режиме. Результат сохраняется обычным
системным диалогом приложения. Исходный PDF не изменяется. При конвертации
из режима редактирования используются текущие изменения PDF.

В XLSX каждая страница получает отдельный лист. Для PDF длиннее 100 страниц
создаётся один лист «Данные», где первый столбец содержит номер страницы.
CSV также содержит номер страницы в первом столбце. Кодировка — UTF-8 с BOM,
разделитель — точка с запятой; кавычки и переводы строк сохраняются корректно.

Текст группируется по координатам в строки и столбцы. Заголовки, примечания
и обычный текст тоже сохраняются. Пустые ячейки между столбцами остаются пустыми.
В XLSX короткие однозначные числа становятся числовыми ячейками; значения
с ведущими нулями, длинные номера и строки с формулами сохраняются как текст.
В CSV потенциальные формулы получают начальный апостроф. При импорте CSV
в Excel задайте текстовый тип столбцам с кодами, чтобы Excel сам не убрал нули.

Конвертация работает с PDF, содержащими текстовый слой. OCR не добавлен.
Сканы без текста не превращаются в пустые таблицы: приложение сообщает,
что требуется OCR. В смешанном PDF страницы без текста отмечаются в результате
и перечисляются в сообщении после сохранения.

PDF хранит расположение текста, а не исходные ячейки Excel. Сложные таблицы,
объединённые ячейки и многострочная вёрстка могут потребовать ручной правки.
Шрифты, рамки, изображения, графики и формулы исходной таблицы не восстанавливаются.

Файл должен быть меньше 500 МБ. Ресурсные пределы: до 10 000 страниц,
100 000 строк, 500 000 заполненных ячеек, 64 МиБ извлечённого текста,
32767 символов в ячейке. Для постраничного XLSX — до 512 столбцов; для CSV
и сводного XLSX — до 511 столбцов данных плюс номер страницы.
При превышении предела появляется ошибка; данные не обрезаются молча.

Проверены реальные PDF, повёрнутые страницы, пустые ячейки, большие документы,
сканы, кириллица, числовые значения, отмена и оба меню конвертации.
Полученный XLSX проверен независимой библиотекой openpyxl. Сборка EXE/APK
и запуск на физическом Windows/Android-устройстве здесь не выполнялись.
